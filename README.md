# Carnet Combat — Prépa Physique

Application de suivi sportif (séances, programmes, poids, compléments, analyse IA), installable sur PC et iPhone et utilisable hors ligne.

Adresse, une fois GitHub Pages activé : https://thierynoa54-coder.github.io/carnet-de-suivis-sportif/

## Installer

- iPhone : ouvrir l'adresse dans Safari, bouton Partager, puis « Sur l'écran d'accueil ».
- PC : ouvrir l'adresse dans Chrome ou Edge, puis cliquer sur l'icône « Installer » de la barre d'adresse.

## Vos données

Elles restent sur chaque appareil, dans le navigateur, jamais dans ce dépôt. Pour changer d'adresse ou d'appareil : Réglages, « Exporter mes données (.json) », puis « Importer des données » sur l'autre.

## Développement

- `node tests/smoke.js` : test automatique (installable, hors ligne, sans erreur) sur PC et iPhone simulé.
