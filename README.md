# Carnet — Prépa Physique

Appli web de suivi d'entraînement pour la préparation physique en sports de combat.

## Fonctionnalités
- **Aujourd'hui / Semaine** : séance du jour et vue hebdomadaire
- **Programmes** : création et modification des programmes et exercices
- **Journal** : historique des séances
- **Analyse** : graphiques et suivi du poids, analyse IA (locale gratuite ou via l'API Claude)
- **Réglages** : profil, compléments, clé API
- Export / import des données en JSON

## Utilisation
Ouvrir `index.html` dans un navigateur. Les données restent dans le navigateur : exporter régulièrement en JSON.
